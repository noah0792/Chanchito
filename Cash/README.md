# Finanzas NI

Aplicación web progresiva (PWA) para registrar ingresos, gastos, transferencias y saldos en córdobas y dólares.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Descomprime este ZIP.
3. Sube todos los archivos que contiene a la raíz del repositorio.
4. En GitHub abre **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Elige la rama `main` y la carpeta `/ (root)`, y guarda.
7. Espera a que GitHub Pages publique el sitio y abre la dirección HTTPS.

## Instalar en iPhone
1. Abre el enlace HTTPS publicado en Safari.
2. Toca **Compartir**.
3. Selecciona **Añadir a pantalla de inicio** y confirma.

En Android, abre el enlace en Chrome y elige **Instalar aplicación** o **Añadir a pantalla de inicio**.

## Datos y privacidad
Los movimientos se guardan localmente en el navegador/dispositivo. Usa la opción de respaldo de la app para exportar tus datos y restaurarlos en otro dispositivo. El ZIP no incluye movimientos personales.

La primera apertura debe hacerse con internet para cargar la app. Después, el modo sin conexión depende del navegador y de que no se borren los datos del sitio.
